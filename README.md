# Nimble Station activity board

A simple team dashboard for workflows in progress.

## How to look at it

**On this Mac**

1. Open Finder.
2. Go to `Desktop / Nimble-GitHub / MOOPsNimbleStationRepo`.
3. Double-click `index.html`.

Chrome/Safari will open the board.

**On GitHub**

Repo: https://github.com/NimbleAdam/MOOPsNimbleStationRepo

The live data is in `data/workflows.json`.  
Change that file, save, commit, and the board updates.

## What this board is for

- Show what is **now**, **this week**, **blocked**, and **which system owns it**
- Give investors/members/team a picture without dumping the whole vault
- Feed the weekly one-pager and the “what we’ve done” video

## What this board is not

- Not GQueues (that is still the real to-do list)
- Not a place for passwords, tokens, or personal email
- Not a claim that blocked items are fixed
